# Sivaa Studio — Capturing Moments That Last Forever

Official website and portfolio for **Sivaa Studio** — premium photography studio based in Chittoor, Andhra Pradesh, capturing weddings, pre-weddings, maternity, portraits, and celebrations.

## Tech Stack

- **Framework**: Next.js 16 (App Router)
- **Styling**: Tailwind CSS & Lucide Icons
- **Database & Storage**: Supabase (PostgreSQL & Storage CDN)
- **Forms**: Google Sheets Webhook Integration & Supabase Inquiries
- **Image Optimization**: Sharp & Next/Image

## Getting Started

1. Clone repository:

   ```bash
   git clone https://github.com/dineshkumar1610-tech/sivaastudio.git
   cd sivaastudio
   ```

2. Install dependencies:

   ```bash
   npm install
   ```

3. Set up `.env.local`:

   ```env
   NEXT_PUBLIC_SUPABASE_URL=your_supabase_url
   NEXT_PUBLIC_SUPABASE_ANON_KEY=your_supabase_anon_key
   GOOGLE_SHEET_WEBAPP_URL=your_google_sheet_webhook_url
   ```

4. Run locally:

   ```bash
   npm run dev
   ```
